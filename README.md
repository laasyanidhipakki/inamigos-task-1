# InAmigos Foundation — NGO Awareness Webpage

## 📌 Internship Project — Task 1

This project was developed as **Task 1 of my internship at InAmigos Foundation**.

The objective of this task was to design and develop a basic awareness webpage to showcase the organization's projects, initiatives, social impact, and opportunities for people to get involved.

## 🌱 About the Project

The webpage presents information about **InAmigos Foundation** and highlights its work in areas such as:

* Education
* Food and community support
* Women empowerment
* Animal welfare
* Environmental conservation
* Skill development

## 🚀 Features

* Clean and responsive NGO awareness webpage
* About InAmigos Foundation section
* Projects and initiatives section
* Social impact statistics
* Project images and gallery
* Volunteer call-to-action
* Functional navigation
* Links to official InAmigos pages
* Responsive design for different screen sizes

## 🛠️ Technologies Used

* HTML5
* CSS3
* Google Fonts
* Responsive Web Design
